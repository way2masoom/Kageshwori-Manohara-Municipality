# Kageshwori-Manohara-Municipality

Electronic Building Permit System (E-BPS) - Frontend Portal for Kageshwori Manohara Municipality, Kathmandu, Nepal.

## Features
- **Public Portal & Landing Page**: Information regarding building permit processes, NBC compliance, and municipal by-laws.
- **Trained Mason Directory**: Live directory of certified earthquake-resilient masons with search, pagination, and Excel export.
- **Registered Designers Directory**: Live directory of authorized architects and civil engineers with search, pagination, and Excel export.
- **Online Designer Registration (Sign Up)**: Comprehensive registration application supporting both individual NEC practitioners and consultancy firms with file uploads, photo preview, client-side validation, and security captcha.
- **Bilingual Interface**: Seamless instant toggling between Nepali (नेपाली) and English without page reloads.
